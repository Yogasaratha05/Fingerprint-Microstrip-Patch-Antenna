# Fingerprint-Shaped Microstrip Patch Antenna

## Project Overview

This project focuses on the design and simulation of a fingerprint-shaped microstrip patch antenna using CST Studio Suite.

## Project Specifications

* **Operating Frequency:** 2.5 GHz
* **Substrate Material:** FR-4
* **Substrate Thickness:** 1.6 mm
* **Application:** Wireless Sensor Networks (WSN)

## Software Used

* CST Studio Suite

## Project Files

* CST project file containing the antenna design and simulation model.
* Simulation result screenshots, including S11, VSWR, gain, and radiation pattern, where available.

## Objective

To design and simulate a compact microstrip patch antenna for wireless communication applications.

## Note

Simulation performance should be verified using the results obtained from the CST project.
